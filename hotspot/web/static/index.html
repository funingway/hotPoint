如何找到网站的 RSS 链接？

常见 RSS 路径：

  • /feed、/rss、/feed.xml、/index.xml
  • /blog/feed、/posts/rss
  • WordPress 站点：/feed/
  • Substack：https://xxx.substack.com/feed
  • Medium：https://medium.com/feed/tag/{topic}

查找方法： 在网页源码中搜索 application/rss+xml 或 application/atom+xml。

占位符示例： https://example.com/search?q={topic}&format=rss，抓取时会自动替换 {topic} 为搜索关键词。
